# Ridiculous at First Glance, Real by the Second

A one-sentence startup pitch that sounds like a joke until the economics click: the product is absurd on its face, the customer is named, and the reason the money works is built into the same sentence. The program validates the sentence (single line, at most 200 characters, exactly one sentence ending in a single period) and writes it to `entry.txt`.

> We rent goats in tiny reflective vests as self-propelled lawnmowers to suburban HOAs, who pay monthly because the goats mow, fertilize, and entertain kids cheaper than any landscaping crew.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/ridiculous-out node main.ts
```
